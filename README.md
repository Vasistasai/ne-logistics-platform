# Northeast Logistics Platform

A regional response and logistics dashboard for Northeast India. This project is separate from the LifeLink repository.

## Live demo

After deployment, visit: https://vasistasai.github.io/ne-logistics-platform/

## Run locally

Requirements: Node.js 22 or later.

```sh
npm ci
npm run dev
```

Create a production build with `npm run build`. Pushing to the `main` branch builds and deploys the site to GitHub Pages using GitHub Actions.
